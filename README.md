# Проект трансграничных переводов

## Описание

Сервис для проведения международных денежных переводов между резидентами разных стран

## Цели проекта

- Обеспечить быстрый и безопасный перевод средств
- Интеграция с банковскими системами 

## Структура документации

- 01-requirements/ — ФТ требования и сценарии, НФТ требования
- 02-architecture/ — архитектурное решение 
- 03-database/ — схема базы данных сервиса
- 04-API/ — спецификация API
- 05-Kafka/ — описание кафка-контракта
- 06-BPMN/ — бизнес-процесс
- 07-Vizion/ — Vizion-документ
